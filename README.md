# CodeMedic - AI-Powered Code Review Assistant

![CodeMedic Logo](frontend/public/code-medic.svg)

CodeMedic is an advanced AI-powered code review application that helps developers improve their code quality through automated analysis and suggestions. Built with modern web technologies, it provides instant feedback on code quality, performance, and best practices.

## 🚀 Key Features

- **AI-Powered Code Analysis**: Utilizes the Deepseek R1 model via Groq API for lightning-fast code reviews
- **Multi-Language Support**: Analyzes code in Python, Java, C, C++, and more
- **Comprehensive Feedback**:
  - Code quality suggestions
  - Performance optimizations
  - Best practices recommendations
  - Time and space complexity analysis
- **Interactive Code Editor**: Built-in code editor with syntax highlighting
- **File Upload Support**: Direct file upload for quick analysis
- **Responsive Design**: Modern UI that works seamlessly across devices

## 🛠️ Technical Stack

### Frontend
- **React.js**: Modern UI framework
- **Tailwind CSS**: Utility-first CSS framework
- **Framer Motion**: Smooth animations and transitions
- **React Icons**: Professional icon set
- **Code Editor**: Custom implementation with syntax highlighting
- **Markdown Support**: For formatted code reviews

### Backend
- **Node.js**: JavaScript runtime
- **Express.js**: Web application framework
- **Groq API**: High-performance AI inference
- **Deepseek R1 Model**: Advanced code analysis capabilities

## 📦 Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/suryanshpandey/codemedic
   cd codemedic
   ```

2. Install dependencies:
   ```bash
   # Backend
   cd backend
   npm install

   # Frontend
   cd frontend
   npm install
   ```

3. Set up environment variables:
   ```env
   # Backend .env
   GROQ_API_KEY=your-groq-api-key
   PORT=3000
   ```

4. Start the servers:
   ```bash
   # Backend
   cd backend
   npm run dev

   # Frontend
   cd frontend
   npm run dev
   ```

## 🔍 Usage

1. Open the application at `http://localhost:5173`
2. Enter your code or upload a file
3. Click "Review Code" to get AI-powered analysis
4. View comprehensive feedback and suggestions
